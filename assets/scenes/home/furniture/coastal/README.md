# ריהוט החוף הפעיל בחדר

כל החלקים נחתכו מגיליונות המקור שהועלו, ללא שינוי בפיקסלים. גיליונות המקור: `source-art/home/coastal/`. גבולות החיתוך לכל חלק ב־`source.json`.

- `sofa/` — מסגרת, כרית גב וכרית מושב.
- `cabinet/` — מסגרת ושתי דלתות, עם עוגן נפרד לכל דלת.
- `lamp/` — בסיס ואהיל.
- `window/` — שלוש חלופות חלון, זוג וילונות ומוט. החדר מציג חלון מלבני עם זוג הווילונות.
- `table/`, `shelf/`, `rug/`, `decor/` — שולחן, מדף, שטיח גלים וצדף.

קובצי `assembly.json` משתמשים בפורמט ההרכבה המשותף של `shared/prop-rig.js`. סידור החדר וגדלי הפריטים, בנפרד למחשב ולנייד, נמצאים בקובץ `../layout.json`. הסט הקודם אינו נטען בחדר.

## זוויות דלתות הארונית

המקור `source-art/home/coastal/cabinet-door-angles.png` נשמר בשלמותו.
ארבעת החיתוכים ב־`cabinet/images/door-{left,right}-{half-open,open}.png`;
גבולות החיתוך ב־`cabinet/door-angles-source.json`.
כל דלת מגדירה `images` בהרכבה. `imageFrame` בפריים בוחר `closed`,
`half-open` או `open`, ומחזיק את האיור עד הפריים הבא בלי למעוך את רוחבו.
בסטודיו תנועת הרהיטים בוחרים דלת ואז ״איור הדלת בפריים״.
טיוטות קודמות נשמרות; כדי להתחיל מהאיורים החדשים אפשר לייצא גיבוי ואז
לבחור ״טעינת הגרסה מהפרויקט״.
