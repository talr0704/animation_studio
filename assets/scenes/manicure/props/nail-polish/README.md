# לק — שמור למשחק עתידי

שלושה חלקים מקוריים עם שקיפות: בקבוק ורוד, טבעת הצוואר ומכסה עם מברשת. החלקים חתוכים מגיליון המקור המשותף לסבון, ללא שינוי בפיקסלים. נתוני המקור וגבולות החיתוך מתועדים ב־`source.json`.

האביזר אינו מחובר למספרה או לעורך. הרכבה, אנימציה וחיבור למשחק יוגדרו כשייבנה המשחק המתאים.
