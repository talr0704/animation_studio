# מומו — ברווז מלח

- `parts/`: 24 חלקים שנחתכו מגיליון המקור. ארבעה פיקסלים של שוליים לכל חלק;
  חלקים סמוכים בודדו לפי ערוץ השקיפות בלי לשנות פיקסלים גלויים של החלק.
- `assembly.json`: הרכבה התחלתית של 18 חלקים. המיקומים עדיין מיועדים לכיול.
- `expressions.json`: העיניים והמקורים החלופיים, שמורים בנפרד להמשך.
- המקור והחיתוכים מתועדים ב־`source-art/characters/momo/`.

פתחי `character-studio.html?character=momo` או `index.html?character=momo&edit=1`.
זהו אותו כלי סידור החלקים של פופה: בחירה, גרירה, גודל, שכבות, ציר וסיבוב.
שמירת מומו משתמשת ב־`momoAssemblyPositionsV1` ואינה משנה את פופה.
אפשר לטעון קובץ הרכבה תואם דרך העורך, ולייצא `momo-assembly.json`.
כדי לפרסם לכולם יש להחליף את `assets/characters/momo/assembly.json` במיקומים
שאושרו. כרגע אין החלפה אוטומטית של כפתור השיחה בדמות שטרם כוילה.

שם הדמות בשיחה ובמשימה הוא מומו. מזהי ההתקדמות ההיסטוריים `milli` ו־
`meet-milli` נשמרו כמזהים פנימיים יציבים כדי לא לאפס היכרויות או משימות קיימות.
