# תנועות מומו — לבדיקה בלבד

`studio-drafts.json` מכיל שבע תנועות התחלתיות: עמידה ומצמוץ, נפנוף,
שמחה, סקרנות, הליכה במקום, שיחה ומנוחה.
`review.json` מסמן `status: draft`, `gameEnabled: false` ו־`approvedClips: []`.
המשחק אינו טוען את הקבצים האלה ולא השתנה מציג מומו הסטטי.

פתחי `character-studio.html?character=momo&mode=animation`.
זהו ציר הזמן הקיים של פופה, עם אחסון נפרד: `momoAnimationEditorDataV1`.

1. בחרי תנועה ולחצי ניגון. אין ניגון אוטומטי בפתיחת המסך.
2. בחרי זמן בלוח או בשדה הזמן. גרירת חלק שומרת לו פריים בזמן הזה.
3. ניתן לערוך ערכים, להוסיף/להעתיק/למחוק פריימים וליצור תנועות חדשות.
4. הראש, הכובע, העיניים, הגבות, המקור וקישוט הכובע נשארים מחוברים בתנועת הראש.
5. הטיוטות נשמרות בדפדפן. ב״שמירה וייצוא״ אפשר להוריד
   `momo-animation-drafts.json`, או להדביק JSON לייבוא. הייבוא נבדק לפני החלפה.
6. מחכים לאישור המשתמשת לפני הוספה להרצת המשחק. הורדה או שמירה אינן אישור.

״סידור חלקים״ ו״אנימציות לבדיקה״ נמצאים באותו סטודיו, עם שמירות נפרדות.
יצירת פריים אינה משנה את `assembly.json`. סידור המראה הבסיסי אינו משנה
מיקומי פריימים קיימים אוטומטית; שינוי ציר לתנועה עצמה נעשה בשדות הפריים.

הקליפים משתמשים בפורמט המקורי של העורך: אוסף `{id: {name,duration,loop,
keyframes}}`, תנועות יחסיות לתנוחת הבסיס וצירים באחוזי קנבס 440×475.
תנועות הלולאה מתחילות ומסתיימות באותה תנוחה כדי למנוע קפיצה.
התנועות חד־פעמיות חוזרות לתנוחת הבסיס בסיום.

```sh
node --test tests/popa-momo-animation.test.js
python3 tests/popa-momo-animation-smoke.py
```
