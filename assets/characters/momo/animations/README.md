# תנועות מומו — לבדיקה בלבד

`studio-drafts.json` מכיל שבע תנועות מתוקנות של המשתמשת: עמידה ומצמוץ, נפנוף,
שמחה, סקרנות, הליכה במקום, שיחה ומנוחה.
`review.json` מסמן `status: draft`, `gameEnabled: false` ו־`approvedClips: []`.
המשחק אינו טוען את הקבצים האלה ולא השתנה מציג מומו הסטטי.

פתחי `character-studio.html?character=momo&mode=animation`.
זהו ציר הזמן הקיים של פופה, עם אחסון נפרד: `momoAnimationEditorDataV1`.

1. בחרי תנועה ולחצי ניגון. אין ניגון אוטומטי בפתיחת המסך.
2. בחרי זמן בלוח או בשדה הזמן. גרירת חלק שומרת לו פריים בזמן הזה.
3. ניתן לערוך ערכים, להוסיף/להעתיק/למחוק פריימים וליצור תנועות חדשות.
4. הראש, הכובע, העיניים, הגבות, המקור וקישוט הכובע נשארים מחוברים בתנועת הראש.
5. הטיוטות נשמרות בדפדפן. ב״שמירה וייצוא״ אפשר להוריד
   `momo-animation-drafts.json`, או להדביק JSON לייבוא. הייבוא נבדק לפני החלפה.
6. מחכים לאישור המשתמשת לפני הוספה להרצת המשחק. הורדה או שמירה אינן אישור.

״סידור חלקים״ ו״אנימציות לבדיקה״ נמצאים באותו סטודיו, עם שמירות נפרדות.
יצירת פריים אינה משנה את `assembly.json`. סידור המראה הבסיסי אינו משנה
מיקומי פריימים קיימים אוטומטית; שינוי ציר לתנועה עצמה נעשה בשדות הפריים.

הקליפים משתמשים בפורמט המקורי של העורך: אוסף `{id: {name,duration,loop,
keyframes}}`, תנועות יחסיות לתנוחת הבסיס וצירים באחוזי קנבס 440×475.
מיקומי הפריימים ותזמוניהם נשמרו בדיוק מהקובץ המתוקן, לרבות תנוחות הסיום.
לא מתבצע תיקון אוטומטי של הפריימים שהמשתמשת ערכה.

```sh
node --test tests/popa-momo-animation.test.js
python3 tests/popa-momo-animation-smoke.py
```

## הבעות פנים

`expressions` בכל תנועה הוא מסלול נפרד עם פריימים `{time, eyes, beak}`.
`eyes`: `open`, `happy`, `closed`; `beak`: `closed`, `smile`, `open`.
האיור מוחזק עד לפריים ההבעה הבא. התנועות המעודכנות כוללות הבעות שמחה,
חיוך, דיבור, מצמוץ ומנוחה מהאיורים המקוריים. קווי הגבות הבסיסיים מוסתרים
בהבעה שמחה/עצומה כדי שלא ייראו כשני זוגות עיניים, וחוזרים כשהעיניים פתוחות.

בחרי זמן, עיניים ומקור ב״הבעות פנים בציר הזמן״ ולחצי ״שמירת הבעה בזמן הזה״.
שינוי הבחירה משהה את הניגון ומציג תצוגה מקדימה; הוא נשמר רק בלחיצה על שמירה.
כפתורי הזמנים מקפיצים לפריימי הבעות קיימים. אפשר למחוק פריים הבעה בנפרד
מתנועות הגוף. ייצוא, ייבוא ושינוי משך האנימציה כוללים גם את מסלול ההבעות.
מעבר לסידור החלקים מחזיר את המראה הבסיסי בלי לשנות את ההרכבה.

המקור שהתקבל נשמר בשלמותו תחת
`source-art/characters/momo/animations/user-corrected.json`.
טיוטות מקומיות משוחזרות רק אם נשמרו ביחס לאותה גרסה מפורסמת של האנימציות.
הטיוטה הישנה אינה נמחקת בטעינה; כתיבה חדשה מתבצעת בעריכה או בייבוא.

### כיוונון ההבעות שאושר

עיניים עצומות מוצגות כקשת דקה ושקועה באמצעות קווי האיור המקוריים
`brow_left.png` ו־`brow_right.png` בהיפוך אנכי, במקום העפעף המלא.
החיוך והמקור הפתוח מקבלים הגדלה נפרדת של 8% סביב מרכזם. המקור הסגור
נשאר בקנה מידה 1 ובאותם מיקום וממדים. הכיוונון מתבצע בתצוגת ההבעות,
ללא שינוי בהרכבה המאושרת או בפריימי התנועה המתוקנים.
