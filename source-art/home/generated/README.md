# סט ריהוט מאויר לבית

שלושה איורים חדשים שנוצרו לפי כיסא המספרה הקיים כרפרנס לסגנון: ספה ורודה, מיטת מנטה ושולחן צד מעץ. גיליון המקור שקוף, בגודל 2172×724.

הפריטים הופרדו משלוש עמודות ברוחב 724, נגזרו לשוליים ונוספה מסגרת שקופה של 12 פיקסלים. קובצי המשחק נמצאים ב־`assets/scenes/home/furniture/`, וגדלים ועוגנים ב־`manifest.json` באותה תיקייה. הפריטים רשומים בקטלוג וזמינים לעיצוב הבית; הסט מוכן לשילוב בסידור הבית.
