# סט ריהוט מאויר לבית

שלושה איורים חדשים שנוצרו לפי כיסא המספרה הקיים כרפרנס לסגנון: ספה ורודה, מיטת מנטה ושולחן צד מעץ. גיליון המקור שקוף, בגודל 2172×724.

הפריטים הופרדו משלוש עמודות ברוחב 724, נגזרו לשוליים ונוספה מסגרת שקופה של 12 פיקסלים. קובצי המשחק נמצאים ב־`assets/scenes/home/furniture/`, וגדלים ועוגנים ב־`manifest.json` באותה תיקייה. הפריטים רשומים בקטלוג וזמינים לעיצוב הבית; הסט מוכן לשילוב בסידור הבית.

## הרחבת הסט והצבה בחדר

`decor-sheet.png` מכיל מנורת רצפה, ארון קטן ותיבת צעצועים, שנוצרו באותו סגנון לפי הספה. כל ששת הפריטים מוצבים בחדר. סידור נפרד למחשב ולנייד נמצא ב־`assets/scenes/home/furniture/layout.json`. גבולות החיתוך המדויקים ושולי השקיפות מתועדים ב־`source.json` ליד קובצי המשחק.

`decor-sheet.png` מוסיף מנורת רצפה, ארון מנטה ותיבת צעצועים, באותו סגנון. כל ששת הפריטים מוצבים כעת בחדר. גבולות החיתוך המדויקים מתועדים ב־`assets/scenes/home/furniture/source.json`; החיתוך שומר את הפיקסלים המקוריים ומשאיר שוליים סביב האיור הנראה, ללא שינוי בגיליון המקור.

`room-background.png` הוא רקע חדר מאויר מלא, ו־`room-rug.png` הוא שטיח שקוף. הם משולבים בחדר במקום האיורים הפשוטים הישנים. קובצי המשחק המקבילים נמצאים ב־`assets/scenes/home/background/room.png` וב־`assets/scenes/home/furniture/rug.png`.
