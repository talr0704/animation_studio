# עורך האביזרים

פתחו `studio.html`, או לחצו על ״עורך אביזרים״ במסך פופה. אפשר לערוך מספריים וסבון עם משאבה. עורך האנימציה הקיים של פופה עצמה נגיש דרך ״עורך הדמות״.

## סידור ויצירת תנועה

1. בחרו חלק מהרשימה או בלחיצה על האיור. ציר הזמן והמיקום מוצגים יחד, ללא החלפת מצבים.
2. בחרו זמן בציר וגררו את האיור או שנו X, Y וסיבוב. כל שינוי שומר אוטומטית פריים בזמן הנבחר. אפשר גם ללחוץ ״הוספת פריים בזמן הזה״ כדי לשמור את התנוחה ללא שינוי. הערכים המוצגים הם המיקום והסיבוב הכוללים באותו זמן.
3. להגדרות משותפות לכל האנימציה פתחו ״צירים וסידור בסיס״ באותו מסך. שם משנים בסיס X/Y, סיבוב בסיס, קנה מידה, שכבה והורה. קשר הורות מעגלי נדחה.
4. סמנו ״גרירה מזיזה את הציר״ כדי לשנות את נקודת הסיבוב בלי להזיז את האיור בזמן הנבחר. ציר נמדד בפיקסלים של תמונת המקור; מיקום נמדד ביחידות הבמה. שינוי ציר מספרי הוא שינוי ישיר של העוגן ואינו מפצה על המיקום. בטלו את הסימון כדי לחזור לגרירת תנועה רגילה. אם יוצרים תנועה לחלק שלא היו לו פריימים, נשמר גם פריים התחלה בזמן אפס.
5. פריימים מכילים שינויים יחסיים להרכבה. שינוי משך התנועה מותח גם את זמני הפריימים. ניתן לבחור מעבר רך או קבוע, לנגן בלולאה ולמחוק פריימים.
6. ״בדיקת הטיוטה במספרה״ פותח מסך מספרה שמשתמש בטיוטה באותה לשונית תצוגה מקדימה. נסו את המספריים לאחר שלבי הטיפול בשיער. מוצג סימון ברור שזו תצוגה מקדימה. היא אינה משנה את המשחק הרגיל או את הקבצים שבמאגר.

הטיוטה נשמרת אוטומטית בדפדפן, לפי מזהה האביזר. ״ביטול שינוי״ מחזיר את השינוי האחרון. ״טעינת הגרסה מהפרויקט״ מחזיר את הקבצים המפורסמים, ואפשר לבטל גם פעולה זו. אם אחסון הדפדפן חסום, יש לייצא קבצים לפני היציאה.

## ייצוא והעלאה

פתחו ״שמירה והעלאה לגיטהאב״. הורידו את קובצי ההרכבה והתנועה והחליפו את הקבצים הקיימים בנתיבים:

```text
assets/scenes/salon/props/scissors/assembly.json
assets/scenes/salon/props/scissors/animations/cut.json
```

אם שיניתם רק תנועה, מספיק להחליף את `cut.json`. אם שיניתם רק סידור, מספיק להחליף את `assembly.json`. אין להעלות מחדש איורים או ליצור קובצי גרסאות נוספים. היסטוריית גיטהאב שומרת את הגרסאות הקודמות.

אפשר לייבא קובץ אחד או שניים יחד כדי להמשיך עריכה. העורך בודק מספרים, סדר פריימים, הורות, מזהה אביזר והתאמה לתמונות שבקטלוג לפני השמירה. קבצים שגויים אינם מחליפים טיוטה תקינה.

קובצי הסבון נשמרים ב־`assets/scenes/salon/props/shampoo/assembly.json` וב־`assets/scenes/salon/props/shampoo/animations/pump.json`. בחירת אביזר בעורך מעדכנת את שמות ההורדה והנתיבים. לכל אביזר טיוטה נפרדת.

## מקור הנתונים המשותף

`assets/catalog.json` מפנה לקובצי האביזר. `assets/scenes/salon/assembly.json` מפנה לאותם קבצים עבור המשחק. `shared/prop-rig.js` מאמת, מרכיב ומחשב את התנועה בשניהם. כך סידור שנשמר בסטודיו אינו מועתק ידנית לקוד המשחק. המשחק ממשיך לבחור את אזור התספורת ידנית; העורך משנה את האביזר בלבד.

פורמט ההרכבה (גרסה 1) כולל `id`, `canvas` ו־`parts`. לכל חלק תמונה, גודל מקור, עוגן, מיקום, קנה מידה, סיבוב, שכבה והורה אופציונלי. פורמט התנועה כולל `prop`, `id`, `duration`, `easing` וערוצים עם `keys` של `time`, `x`, `y`, `rotation`.

כדי לחבר אביזר נוסף נדרשים קובצי נתונים בפורמט הזה, רישום `editable`, `assembly`, `animation` ו־`images` בקטלוג, וחיבור המנגנון המשותף במקום שבו אותו אביזר מוצג במשחק. אין לסמן אביזר כעריך לפני שהחיבור למשחק הושלם.
