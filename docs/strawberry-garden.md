# גינת התותים — השלב הבא אחרי מומו

אחרי קבלת ההזמנה ממומו, כפתור ״לגינה״ פותח שלוש ערוגות. בכל ערוגה
שותלים, משקים וממתינים 20 שניות לפני קטיף. בערוגה הראשונה גוררים כעת
את המשפך ומשקים את האדמה בתנועה; ראו `docs/watering-interaction.md`. ההמתנה אינה
מתחילה עד ההשקיה. אפשר לצאת ולרענן: זמן המוכנות נשמר לפי שעון אמיתי.

כל ערוגה מעניקה תות אחד פעם אחת. בקטיף השלישי נשמרים באותה כתיבה
הערוגה שנקטפה, התות במלאי, קבלת הפעולה והמעבר ל־`bake-with-bonnie`.
לא ניתנים מטבעות ולא נצרכים התותים עד למערכת האפייה העתידית.
אין עדיין בוני פעילה או מסך אפייה. המשימה אינה מושלמת בשלב הזה.
שלושת השתילים שייכים למשימת ההיכרות; אין כאן עדיין חנות זרעים או מחזורי גידול חוזרים.

- `game/farming/strawberries.js`: כללי השתילה, ההשקיה, הגדילה והקטיף.
- `game/farming/garden.js`: מסך הערוגות, מלאי, הודעות ומעבר למסכים הקיימים.
- `game/farming/garden.css`: פריסה רספונסיבית וכפתורים.
- `assets/scenes/garden/props/10-strawberry-garden/images/`: חלקי האיור המקוריים של הערוגה, השתילים והתותים.
- `game/game.js`: חיבור לאחר השיחה עם מומו. לפני קבלת המשימה הגינה
  ממשיכה לפתוח את משחק הפירות הקיים; לאחר מכן הוא זמין בכפתור נפרד בגינה.

השמירה היא `localStorage.popaProgressV1`, באותם שדות מלאי ומשימה קיימים.
מזהי הערוגות הם `first-cake-1` עד `first-cake-3`. מוכנות מחושבת מתוך
`readyAt` בכל כניסה ותצוגה, בלי לשכתב את השמירה בטיימר. שינוי שעון לאחור
מעכב את המוכנות ואינו מאפשר קטיף מוקדם. אין שרת זמן או סנכרון בין מכשירים.
כשאין אחסון זמין, הפעולות עובדות לביקור הזה ומוצגת הודעה מפורשת שהשמירה זמנית.

```sh
node --test tests/popa-strawberries.test.js tests/popa-progress.test.js
python3 tests/popa-strawberries-smoke.py
```

## רקע הגינה

הרקע שהועלה `Cozy Sunny Garden with Empty Plots.png` נמצא ב־`assets/scenes/garden/background/sunny-garden.png`, ללא שינוי בפיקסלים. השתילים ממוקמים על שלוש הערוגות שבאיור. `game/farming/layout.js` שומר על יחס הממדים; בנייד לאורך המצלמה עוברת בין הערוגות בכפתורים, ובמסך רחב שלושתן מוצגות יחד. הגינה אינה מוסיפה את מסגרות העץ מעל הערוגות שברקע.
