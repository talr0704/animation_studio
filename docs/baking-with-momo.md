# אפייה עם מומו

אחרי קטיף שלושת התותים, כפתור ״למטבח האפייה עם מומו״ בגינה פותח
`bakery.html`. אפשר להגיע גם דרך השיחה עם מומו בשלב האפייה, או דרך חזית
המאפייה ברחוב. מסך סידור המטבח נשמר בנפרד.

המסלול הפעיל משתמש באיורי המשתמשת:

1. לוחצים על הסל או גוררים אותו לקערה כדי להעביר תות אחד בכל פעם.
2. מוסיפים קמח, ביצה וחלב מהמזווה. אלו חומרי הסדנה, ללא רכישה או תגמול במטבעות.
3. מערבבים שלוש פעמים עם המטרפה.
4. מכניסים לתנור וממתינים שמונה שניות לפי זמן אמיתי.
5. מוציאים את העוגה, מקשטים בתות ואורזים אותה.

מומו מלווה את הסדנה באנימציות המאושרות; פופה שומרת על הבגד שנבחר במשחק.
המקשים Enter/Space מפעילים את הכפתורים, והעברת התותים במגע מתבצעת בלחיצה.

## שמירה

`game/baking/recipe.js` מנהל את הכללים דרך אותו `progressStore`.
השדה האופציונלי `baking` נוסף לשמירה בגרסה 1 בלי לאפס שמירות קיימות:

- `stage`: `prep`, `mixed`, `baking`, `baked`, `decorated`, `packed`.
- `strawberries`: מספר התותים שכבר הועברו מהמלאי לקערה, 0–3.
- `ingredients`: האם נוספו `flour`, `egg`, `milk`.
- `mixes`: 0–3 פעולות ערבוב.
- `readyAt`: זמן סיום האפייה במילישניות, או null לפני הכנסת העוגה לתנור.
- `decoration`: null או `strawberry`.

העברת תות צורכת אותו מהמלאי ושומרת אותו בקערה באותה כתיבה. ברענון הוא נשאר
בקערה ואינו מחויב שוב. לא מוחזר מלאי אוטומטית בגלל יציאה מהעמוד.
האריזה שומרת יחד עוגה אחת במלאי, מונה מתכון, תיעוד אפייה עם מומו והמעבר
ל־`deliver-cake`. מזהי הפעולה קבועים למסלול כדי למנוע פרס כפול.
אין כאן עדיין מסירה או פרס סיום סיפור.

מזהה השלב הטכני `bake-with-bonnie` נשאר לתאימות לשמירות; כל הטקסט והדמות
במשחק הם מומו. שדות ההתקדמות הישנים של בוני אינם נמחקים ואינם מופעלים.
השמירה מקומית בדפדפן. כשל שמירה מוצג במפורש כביקור זמני.

## קבצים ובדיקות

- `bakery.html`, `game/baking/bakery.js`, `game/baking/bakery.css`: מסך המשחק.
- `game/baking/recipe.js`: כללי הכנה ושמירה, ללא תלות ב־DOM.
- `game/progress/state.js`: אימות נתוני האפייה והפקודה האטומית.

```sh
node --test tests/popa-baking.test.js tests/popa-progress.test.js
python3 tests/popa-baking-smoke.py
python3 tests/popa-momo-room-size-smoke.py
python3 tests/popa-first-meeting-smoke.py
python3 tests/popa-strawberries-smoke.py
```
