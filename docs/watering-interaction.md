# פיילוט השקיה — ערוגה ראשונה

אחרי שתילה בערוגה הראשונה לוקחים את המשפך המאויר מהדשא וגוררים אותו מעל
האדמה סביב השתיל. המשפך מורכב מחלקי האיור שהועלו: גוף, ידית ופייה.
הוא נוטה כשהפייה נמצאת בגובה ובמיקום מתאימים להשקיה. הטיפות יוצאות
מהפייה ונופלות על האדמה, העלים נעים בעדינות והקרקע מתכהה.

נדרשת השקיה קצרה בשלושה אזורי אדמה, במרכז ובשני הצדדים. עמידה מעל נקודה
אחת אינה מסיימת את כל הפעולה. שלוש טיפות ליד השתיל מציינות אילו אזורים
כבר קיבלו מים. שחרור הכלי, ביטול מגע, הסתרת הלשונית או יציאה מהמסך עוצרים
את ההשקיה. שינוי גודל המסך בזמן גרירה מבטל את האחיזה.

ההשקיה מוצגת מנקודת המבט של השחקנית: פופה אינה מוצגת בגינה.
המשפך נע ישירות לפי תנועת היד. תנועת העלים והמעבר לשתיל הבא נשארים מעוגנים בשורש. העדפת הפחתת תנועה מפסיקה
את התנודות והמעברים האוטומטיים; כלי ההשקיה והמשוב נשארים שמישים.

## תרגול ושמירה

לקיחת המשפך כשאין שתיל שממתין להשקיה מפעילה שתיל תרגול, גם אם הערוגות כבר נקטפו.
התרגול אינו מעניק פריטים, אינו יוצר קבלות פעולה ואינו משנה את המשימה.
Escape או מעבר לערוגה אחרת מחזירים לגינת המשימה; השער המאויר מוביל הביתה.

בשימוש במשימה, רק סיום ההשקיה מפעיל את פעולת `water` הקיימת. אז נכתבים
זמן ההשקיה וזמן המוכנות לתות, פעם אחת. לפני הסיום, הרטיבות החלקית היא
משוב לביקור הנוכחי ואינה יוצרת כתיבות שמירה בכל פריים. יציאה מהגינה
מנקה את התרגול ואת מדידת המים החלקית; השקיה שהושלמה נשארת בשמירה.
הקרקע הרטובה בשלב הגדילה נגזרת מהמצב השמור גם אחרי רענון.

## מקלדת

Tab למשפך, חצים להזזה, Shift וחצים להזזה עדינה, רווח או Enter להחזקת
זרם המים, Escape להחזרת המשפך. במגע גוררים עם האצבע בלי גלילת המסך.

## קבצים

- `game/farming/watering-progress.js`: מדידת זמן השקיה לכל אזור, בלי DOM.
- `game/farming/watering.js`: גרירה, מקלדת, מים, משוב וביטול.
- `game/farming/garden.js`: חיבור למשימה ולשתיל התרגול.
- `game/game.js`: חיבור מסך הגינה למצב משחק בגוף ראשון.

הפיילוט מחליף את לחיצת ההשקיה בערוגה הראשונה. ערוגות 2–3 ופעולות השתילה,
הקטיף והאפייה עדיין משתמשות באינטראקציות הקודמות; זהו שלב ראשון לליטוש.

```sh
node --test tests/popa-watering.test.js tests/popa-strawberries.test.js
python3 tests/popa-watering-smoke.py
python3 tests/popa-strawberries-smoke.py
python3 tests/popa-baking-smoke.py
```

## ממשק בתוך האיור

הכרטיס המרכזי, תוויות הפעולה והכפתורים בתחתית הוסרו. השער המצויר הוא
היציאה הביתה, דלת הבקתה נפתחת למטבח אחרי הקטיף, והעץ מוביל למשחק הפירות.
הסל מציג כמות קטנה במקום טבלת מצב. הנחיות קצרות מופיעות למספר שניות בלבד.
חיצים עדינים מאפשרים להזיז את המצלמה כשהתמונה רחבה מהמסך; אין תפריט
ממוספר לערוגות. כפתורי הניווט והסטודיו הכלליים מוצגים שוב בחזרה הביתה.
כל יעדי האיור נשארים פקדים סמנטיים למקלדת ולקורא מסך, עם שמות נגישים.
